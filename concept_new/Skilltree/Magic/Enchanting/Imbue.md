# Imbue (replaces Fire Aspect)

Sub-tree: [[Enchanting]] · Slot type: **Toggle**

*Old: Enchanting.md linked "Fire Aspect" but had no note.*

## Design
- Weapon hits (melee and ranged, not spells) apply an **element**:
  - **Fire:** Burn 2 s
  - **Ice:** Slow 1.5 s (so it sets up [[Icicle]] and Ice Trident shatters)
  - **Poison:** +1 Poison stack
- Only elements whose Elemental skill you own can be chosen ([[Fire Ball]] → Fire, [[Icicle]] → Ice, [[Poison Darts]] → Poison). With none of those skills, Imbue can't be activated.
- Pressing the hotbar key while Imbue is active **cycles** to the next owned element. The HUD icon shows the current element.

## Starting values
| Drain | Fire | Ice | Poison |
|---|---|---|---|
| 2.5 mana/s | Burn 2 s | Slow 1.5 s | 1 stack |
