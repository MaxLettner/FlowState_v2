# Loadout (Hotbar)

- **4 hotbar slots** on keys **1–4**. In the skill tree, any unlocked skill, basic weapon or the Rusty Sword can be assigned to a slot.
- Each skill has one of two **slot types**:
  - **Attack** (weapons, attack spells): pressing the key makes it the *active attack*. **LMB** uses the active attack, and **RMB** uses that weapon's secondary action if it has one.
  - **Toggle / Instant** (Levitation, Mana Shield, enchantments): pressing the key activates or deactivates it immediately without changing the active attack.
- Only **one enchantment** can be active at a time. Activating another one replaces it.
- Melee and Ranged have separate attack cooldowns, so switching weapons does not reset or skip a cooldown.
