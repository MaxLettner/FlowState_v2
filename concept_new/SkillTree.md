# Skill Tree

The skill tree has three branches. Each branch has one **stat node** that can be bought several times (ranks) and three **sub-trees**. Each sub-tree grants a basic weapon or spell plus a passive, and holds three skills.

| Branch | Stat node | Sub-trees |

| [[Magic]] | [[Mana]] | [[Arcane]] · [[Elemental]] · [[Enchanting]] |

## Starting state
The player starts with the **Rusty Sword** (not part of the tree) in hotbar slot 1:
medium damage (10), medium speed (0.6 s), 1 % crit, light knockback.
