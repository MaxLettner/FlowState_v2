# Changes from the old concept

| Area | Old concept | New concept |
|---|---|---|
| Melee sub-trees | Index linked One Handed / Two Handed / Spear; weapons were in Swords / Fisticuffs / Blunt | **Swords / Fisticuffs / Blunt** (index fixed) |
| Stat nodes | "Gives more X, satisfies requirements" | Repeatable **ranks**; skills require ranks, see [[Progression]] |
| Unlocking | Not defined | All skills unlockable; each additional skill in the same sub-tree costs more |
| Loadout | Not defined | **4-slot hotbar** (keys 1–4) + RMB for weapon secondaries, see [[Loadout]] |
| Sub-tree nodes | Empty (Bow.md, Crossbow.md) | Each grants a **basic weapon/spell** and a **passive** |
| Status effects | Mentioned loosely (DOT, stun, slow, freeze) | Defined once in [[Status Effects]] |
| Levitation | Continuous flight, no initial cost | **Timed burst**: activation cost, 3 s flight, cooldown |
| Magic Missile | Homing | Aim at the cursor, then **home on the enemy nearest the cursor** |
| Mana Shield | Damage reduction, continuous drain | **Damage is paid with mana** instead of HP |
| Fire Ball | Straight, AOE, DOT | **Charged**: longer charge → bigger explosion + longer **burning ground** |
| Icicle | "shoots icicle" | **Slow + shatter** |
| Poison Darts | Stackable DOT | **3-dart spread**, each hit = 1 poison stack |
| Fire Aspect | Link without a note | Replaced by **Imbue** (weapon hits apply an element) |
| Life Steal | Heal from damage dealt | **Heal on kill** |
| Piercing | +pierce to projectiles | Kept: +2 pierce (+1 for the Recall Trident) |
| Shortsword | Balanced | **3-hit combo** with a finisher |
| Dual Wielding | 2 katanas, fast | **Alternating blades**, two swings can overlap |
| Zweihander | Slow, big | **Charged cleave** on hold |
| Fisticuffs | Stun + ×2 on crit | **Combo meter** raises crit; crits deal ×2 and stun |
| Leather / Metal / Spike | Stat lines only | + **dodge** / + **block** / + **bleed** |
| Hammer | Stun + knockback | + **mid-air ground slam** |
| Morningstar | Long, high knockback | **Flail spin** on hold |
| Spring Hammer | Fast, extreme knockback | + launched enemies **damage what they crash into**; knockback into pits kills |
| Shortbow | Fast, short, weak | Kept as written (fast click shots) |
| Bone Bow | Medium everything | + **shattering arrows** (bone shards) |
| War Bow | Heavy, pierce 3 | **Charged draw** |
| Dual Crossbow | Two shots, then reload | Kept: **burst of 2 + reload** |
| Heavy Crossbow | Rail bolt | + **pins** the last enemy to the wall |
| Poison Crossbow | First hit poisons | Kept as written |
| Trident | Melee + ranged, doesn't return | LMB **stab**, RMB **throw**, walk over it to pick it up |
| Recall Trident | Comes back | **RMB again recalls**; it hits enemies on the way back |
| Ice Trident | AOE freeze, slow on melee | Kept + frozen enemies **shatter** |
| Heavy Trident | Long windup | **Charged windup** (minimum windup, more power when held) |
