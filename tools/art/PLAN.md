# Art & animation overhaul — status / plan

User request (2026-11-18): improve all assets (much more detailed, still pixel art), distinct textures per
enemy type, make the player stand out, add more animations, make existing ones smoother.

## Status (2026-11-18): COMPLETE
All art is generated by `python tools/art/generate_all.py` into `src/main/resources/assets/textures`
and integrated in Java. Backup of the pre-overhaul sources: `src_backup_pre_art_overhaul.tar.gz`.

### Java integration (done)
- `Assets`: `pixels(name, scale)` (nearest-neighbour upscale, cached), `frames()`, `frameImage()`, `sprite()`, `raw()`.
- `Visuals/`: `Frames`, `FrameSprite` (self-updating FXGL View), `Particles` (hit sparks, splats, dust, embers,
  status particles), `WeaponArt` (places diagonal weapon textures by handle/tip).
- `SpriteComponent` rewritten: strips per state, air frame by vy, land/attack one-shots, smooth turn,
  hit flash, i-frame blink, player glow, frozen overlay, stun stars, mana-shield bubble.
- Melee swings use WeaponArt + arc trail; tridents/spear re-anchored; bows/crossbows aimed with draw/reload
  frames (`HeldWeaponComponent.spawnAimed`); gloves + MetalGuard sprites; all projectiles sprite-based;
  `BlastComponent.Style` (FIRE/ICE/DUST) animated blasts; animated burning ground; chest strip animation;
  textured terrain (world-anchored ImagePattern); 2-layer parallax (hellish abyss: horned colossus, fangs, black pit) + sparse ambient embers.
- Fixed chest double-attach warning (`build()` instead of `buildAndAttach()`).
- Effects/swings now render above terrain (z 12-15).

### Possible follow-ups
- Old unused textures were deleted 2026-11-18 (still in src_backup_pre_art_overhaul.tar.gz).
- Projectile trails were not added (only fireball embers via burning ground / blasts).

## Done so far
- `pixel.py` — helpers (ramps, band-dithering, outline, strip, ellipse, line).
- `materials.py` — colour ramps (steel, rust, wood, gold, bone, ice, crimson, teal, purple, ...).
- `slimes.py` — reviewed & approved look. 64x64 frames, bottom anchor at (32, 62), intended display x2.
  - Player: cyan slime + red bandana with fluttering tails (stands out); EnemyBrute (melee): green, horns,
    angry eyes, teeth; EnemyHunter (ranged): orange, feather headband, war paint.
  - Strips: `<Name>_idle` (6), `_walk` (8), `_air` (4: rise fast, rise, apex, fall), `_land` (4),
    `EnemyHunter_attack` (4), plus `FrozenOverlay.png`.
- `weapons.py` — reviewed & approved 2026-11-18. Diagonal convention: canvas S x S,
  2px margin, handle end bottom-left (2, S-3), tip top-right (S-3, 2). Canvas size from target display
  length at scale 2 (`canvas_for_length`).
- `ranged.py` — reviewed & approved 2026-11-18. Bows: 3-frame strips (rest/half/full, nocked arrow drawn in
  frames 1-2), grip at the right edge, centred vertically. Crossbows: 2-frame strips (loaded/empty), grip
  pivots in `PIVOTS`. Includes the new HeavyCrossbow and PoisonCrossbow.
- `projectiles.py` — reviewed & approved 2026-11-18. Gloves (fists pointing right, ~13x12) + MetalGuard plate;
  arrows/bolts pointing right; BoneShard (3 variants); animated ArcaneBolt/Spark (4f), MagicMissile (3f),
  FireBall (4f, head centre in `CENTERS`); Icicle, PoisonDart.
- `effects.py` — reviewed & approved 2026-11-18. Explosion_fire (7f), Explosion_ice (6f), Shockwave_dust (6f,
  72x24), BurningGround (4f, 16x16 tileable), MagicShield (4f, 52x52 translucent), StunStars (4f), Chest
  (8f, 40x34; anchors described in the module docstring).
- `terrain.py` — drafted, awaiting review. Ground 64x64 basalt + GroundTop 64x12 crust (Ground bodies are
  DARKSLATEGRAY rects today), Platform 32x32 brown bricks + PlatformTop 32x8 (structures, SADDLEBROWN today),
  bg_far / bg_mid at 480x216, seamless horizontally, meant for x5 parallax.
- Nothing has been written into `src/main/resources/assets/textures` yet and no Java changed for the art.
  Previews were only rendered to the scratchpad.

  frozen overlay sprite, chest animation, textured terrain via world-anchored ImagePattern, 3-layer parallax.
